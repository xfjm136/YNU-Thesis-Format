# 云南大学本科生学年/毕业论文格式要求核查清单

This reference condenses commonly used Yunnan University undergraduate year-paper / graduation-thesis formatting requirements. For undergraduate graduation theses/design papers, prefer `ynu-2024-undergraduate-thesis-writing-spec.md`, which is derived from the official 云大本科〔2024〕54号 PDF. If the user supplies a newer official file, department template, or course-specific standard, use that file first.

## Document Structure

- Generic sequence for year papers and graduation theses: Chinese abstract, Abstract, table of contents, body, references, acknowledgement, appendix when needed.
- Cover, evaluation form, title page, originality statement, authorization page, and similar front-matter forms are template-specific. Do not require or insert them unless the user supplies an official template/department rule or explicitly asks for those pages. If they are present, audit them against the supplied template rather than this generic checklist.
- Body contains introduction/preface, main discussion, and conclusion.
- Abstract should summarize content, method, views, results, conclusions, and innovation; generally 300-500 Chinese characters.
- Keywords: 3-5 terms, Chinese semicolon-separated, no terminal punctuation.
- Abstract and Key Words must correspond to the Chinese abstract and keywords.
- References cited in the text must appear in the references list; GB/T 7714-2015 formatting is required.

## Heading Systems

Choose one system and keep it consistent. The second system explicitly permits `第一章` + `第一节` + `一、` + `（一）`; do not mark that combination as mixed:

| Level | First system | Second system | Third system |
|---|---|---|---|
| 1 | 一、 | 第一章 | 1 |
| 2 | （一） | 第一节 | 1.1 |
| 3 | 1. | 一、 | 1.1.1 |
| 4 | （1） | （一） | 1.1.1.1 |

Heading formatting:

- First-level heading: 三号黑体, centered.
- Second-level heading: 四号黑体.
- Third and lower headings: 小四黑体.
- Chapter title spacing: before 0.8 line, after 0.5 line.
- Section title spacing: before 0.5 line, after 0 line.
- Third and lower heading spacing: before 0, after 0 unless a supplied template differs.
- Introduction and conclusion should each be independent chapters. `结论` normally has no chapter number in the YNU example.

## Page Setup

- Paper: A4.
- Margins: top 2.5 cm, bottom 2.0 cm, left 3.0 cm, right 2.0 cm.
- Character spacing: standard.
- Body line spacing: fixed 22 pt.
- Body Chinese font: 宋体, 小四.
- English letters and Arabic numerals: Times New Roman, 小四.
- Body paragraph: justified, first-line indent 2 Chinese characters.

## Page Numbers And Headers

- Template-specific front matter, such as cover, evaluation form, originality statement, and authorization page: do not require it in generic checks. If present and the supplied template says so, it usually has no displayed page number.
- Abstract, Abstract, and TOC: uppercase Roman numerals `Ⅰ, Ⅱ, Ⅲ, ...`, footer center, 五号.
- Body, references, acknowledgements, and non-independent appendix: Arabic page numbering in footer center using `第×页（共×页）`, 五号.
- Header starts from body page 1.
- Header font: 五号宋体, centered.
- Header content: complete current first-level heading.

## Abstracts

- Chinese abstract starts on a new page.
- Title: `摘　　要`, three-point/full-width spacing between characters, 三号黑体, centered.
- English title: `Abstract`, 三号 Times New Roman, centered.
- Abstract content: 小四, fixed 22 pt, justified, first-line indent 2 characters.
- `关键词：` and `Key Words：` labels are bold.
- Chinese keywords use Chinese semicolons; English keywords use English semicolons; no final punctuation.

## Table Of Contents

- Must be automatically generated.
- Title: `目　　录`, 三号黑体, centered, two full-width spaces between characters.
- No blank line between TOC title and TOC entries.
- Include Chinese abstract, Abstract, headings through level 3, references, acknowledgements, and appendices.
- Level 1 entries: top-aligned, 小四黑体.
- Level 2 entries: indent 2 characters, 小四宋体.
- Level 3 entries: indent 4 characters, 小四宋体.
- Dot leaders and right-aligned page numbers.
- Fixed 22 pt line spacing.
- TOC entries must match body headings and page numbers.

## Citations And Notes

- Use sequential numeric citation style.
- Citation numbering follows first appearance order.
- Citation marker uses square brackets, such as `[1]`.
- Complete-sentence citation markers should appear after sentence punctuation without extra space.
- Explanatory notes use footnotes at page bottom, generally with circled numbers.
- Headings must not contain citation markers.
- No broken cross-reference fields are allowed.

## Figures, Tables, And Formulas

Figures:

- Figure number and title below the figure, centered.
- Chapter-based numbering, e.g. `图 1.3`.
- No repeated or skipped figure numbers.
- One full-width space between figure number and figure title.
- Figure title Chinese font 黑体, numbers/letters Times New Roman, 小四.
- Figure and caption should not split across pages.

Tables:

- Table number and title above the table, centered.
- Chapter-based numbering, e.g. `表 1.3`.
- No repeated or skipped table numbers.
- One full-width space between table number and table title.
- Table title Chinese font 黑体, numbers/letters Times New Roman, 小四.
- Table body Chinese font 宋体, numbers/letters Times New Roman, 五号.
- Table and caption should not split across pages.

Formulas:

- Use Word equation editor / Office Math objects.
- Place formula on its own centered line.
- Number formulas by chapter using parentheses, e.g. `（1.3）`.
- Formula number is at the right edge of the line.
- No dotted leader between formula and number.
- Long formulas break before `=` or at `＋、－、×、÷`; operator appears at start of the new line.

## References, Acknowledgement, Appendix

References:

- Start on a new page.
- Title: `参考文献`, 三号黑体, centered.
- No blank line between title and entries.
- Entry text: 小四宋体 / Times New Roman, fixed 22 pt, justified.
- GB/T 7714-2015 bibliographic style.

Acknowledgement:

- Start on a new page.
- Title: `致　　谢`, 三号黑体, centered, two full-width spaces.
- Content: 小四宋体 / Times New Roman, fixed 22 pt, justified, first-line indent 2 characters.

Appendix:

- Start on a new page when present.
- Title format follows first-level heading style.
- Multiple appendices use `附录 1`, `附录 2`, etc.

## Formatting-Only Guard

Allowed automatic changes:

- Page setup, margins, paper size.
- Style definitions and direct paragraph/run formatting.
- Existing header/footer font, alignment, and page-number formatting.
- Existing TOC refresh/rebuild when it does not alter headings.
- Existing field update when it does not create errors.
- Section/page breaks needed for required independent pages.
- Figure/table/formula paragraph alignment and font formatting.

Forbidden automatic changes unless explicitly requested:

- Rewriting paragraphs.
- Changing heading text or title-numbering text.
- Changing formula meaning.
- Changing citation numbers, reference entries, figure/table captions, or data.
- Adding missing academic content.
- Adding or forcing cover pages, evaluation forms, originality statements, authorization pages, or other non-universal template pages.
